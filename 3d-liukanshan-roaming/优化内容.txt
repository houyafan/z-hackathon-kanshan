3D 刘看山漫游角色技能扩展实现方案（无代码版）
一、方案概述
本方案基于现有 Three.js 3D 刘看山漫游封装能力，纯前端表现层扩展，不侵入业务逻辑、不修改底层渲染架构，所有新增技能均通过标准化 API 调用，与内容养成、游历养成、互动社交等业务场景无缝对接，实现 “业务触发→3D 表现→用户感知” 的完整闭环。
二、设计原则
1.表现 - only 原则：仅负责 3D 动画、状态展示、气泡提示、位移引导，无数据计算与业务逻辑。
2.无侵入扩展：复用现有容器、画布、模型加载与移动内核，不重构底层代码。
3.标准化 API：统一调用风格，业务侧可无感接入，支持链式调用与状态回调。
4.性能友好：动画轻量化、状态可中断、资源可复用，不增加设备性能负担。
三、核心技能模块与实现方案
（一）游历事件技能模块
1. 游历启动
•实现方式：接收游历类型参数，触发模型状态切换，播放对应游历待机动画，隐藏模型本体并显示游历进度提示，同步更新语音气泡文案。
•效果匹配：北极 / 山海 / 城市 / 知识渔场四种类型对应不同背景提示、气泡文案与动画姿态。
•联动能力：支持传入游历时长，进度条自动倒计时，可被外部指令提前终止。
2. 游历归来
•实现方式：中断游历状态，模型从屏幕边缘滑入恢复显示，播放归来特效动画，弹出旅行手账提示卡片，自动切换到达语音气泡。
•扩展能力：支持传入带回内容信息，手账卡片可展示内容标题与简介，支持点击回调触发业务跳转。
3. 游历中断
•实现方式：立即停止游历倒计时与动画，模型快速返回原位，恢复默认待机状态，不触发归来完整流程。
（二）成长进化技能模块
1. 等级升级
•实现方式：接收等级参数，触发升级光效动画，模型执行缩放 / 姿态切换，同步播放升级提示气泡，支持幼崽→成长→成年三阶段形态切换。
•视觉表现：叠加发光、闪烁等轻量化特效，动画结束后固定新形态，支持状态持久化。
2. 装扮切换
•实现方式：基于同一模型替换材质 / 纹理 / 局部配件，触发换装淡入动画，切换后保持对应游历场景适配外观，支持限定装扮快速切换。
（三）内容养成与状态技能模块
1. 内容养成
•实现方式：接收内容类型参数，触发点头 / 进食等反馈动画，学识值提升气泡上浮提示，动画时长固定且可被中断。
•适配场景：普通内容、盐选内容、视频内容对应不同反馈强度，表现统一不区分数据差异。
2. 状态切换
•实现方式：支持正常、开心、疲倦、休眠四种基础状态，通过模型透明度、姿态、动画循环、气泡文案区分表现。
•休眠唤醒：休眠状态下模型暗化、停止移动与交互，接收唤醒指令后恢复亮度与待机状态。
（四）内容引导与推荐技能模块
1. 指向引导
•实现方式：接收页面元素参数，计算元素中心坐标，模型转向目标位置，播放指向动作动画，同步弹出引导气泡。
•联动能力：支持指向完成回调，可串联分步引导流程，不影响原有移动逻辑。
2. 内容推荐卡片
•实现方式：在模型上方弹出轻量化推荐气泡，支持展示内容标题、标签、来源信息，点击气泡触发外部回调跳转内容页。
•显示规则：自动适配屏幕位置，不遮挡核心内容，显示时长可配置，到期自动消失。
（五）互动动作技能模块
1. 预设动作播放
•实现方式：内置摸头、挥手、跳跃、坐下、钓鱼、漫步等标准化动作，接收动作类型参数后立即执行，单次动作执行完毕自动恢复待机。
•中断机制：新指令可立即覆盖当前动作，无卡顿与动画残留。
2. 点击互动反馈
•实现方式：监听模型点击事件，触发随机轻量互动动作与心情气泡，不影响业务层点击逻辑，可开启 / 关闭。
（六）社交联动技能模块
1. 好友串门
•实现方式：接收好友数据参数，模型执行短距离移动动画，短暂停留后返回原位，弹出串门提示气泡，无复杂逻辑仅做表现。
2. 成就展示
•实现方式：模型旁弹出成就 / 勋章图标，播放短暂展示动画，自动消失，支持传入勋章名称与等级信息。
四、技术实现架构
1. 内核复用
•复用现有 Three.js 渲染、模型加载、位移控制、气泡管理核心能力，不新增独立渲染实例。
•沿用现有 CSS 样式体系，新增动画与提示均基于原有 class 扩展。
2. 状态管理
•内部维护游历、成长、状态、动作四类状态，互斥执行高优先级指令，避免动画冲突。
•提供状态查询接口，业务侧可实时获取当前模型状态。
3. 回调机制
•所有技能均支持完成回调、点击回调、中断回调，业务侧可精准控制流程衔接。
4. 兼容性与性能
•所有动画基于模型姿态与纹理切换实现，无额外 heavy 特效，适配低配置设备。
•支持极简模式关闭动画，仅保留基础展示，降低性能占用。
五、接入与迁移方案
1. 无感接入
•新增技能不修改现有 API，原有 init、setMessage、moveTo 逻辑完全兼容。
•业务侧仅需调用新扩展方法，无需调整 HTML 结构与样式引入。
2. 分步上线
•支持按模块单独上线：优先上线游历→成长→养成→引导，逐步开放全部技能。
•无依赖关系，单个模块上线不影响其他功能使用。
3. 配置化管理
•所有动画时长、气泡文案、特效强度支持初始化配置，无需修改技能包源码。
•支持自定义动作与状态，适配业务个性化需求。
六、边界与约束
1.不实现业务逻辑：不处理内容推荐算法、用户数据统计、养成数值计算、防刷机制。
2.不存储用户数据：所有状态、等级、装扮、游历信息均由业务侧传入与维护。
3.不冲突页面交互：所有点击、移动、引导均不干扰页面原有操作，可随时关闭。
4.不依赖后端接口：纯前端表现技能，所有数据通过参数传入，无网络请求。
